- residual_risks:
  1. 同模型自评的橡皮图章风险（与 M0–M4 相同）。缓解：结论一律落成可复现命令或永久门禁。
  2. **没有线上验收**（同 M3/M4）：整套 M5 只在本地 workerd / 本地 `wrangler dev --local`
     上验证。真实边缘上的 D1 复制延迟、跨 DO 调用失败率、跨区域延迟仍未测。
  3. **群成员变更与群频道系统消息不是同一事务**（ECN-0008 偏差 7）：极端情况下成员关系
     已成立但群里少一条加入提示。取舍见 ECN。
  4. **多目标群组操作遇到满员时逐目标原子**（ECN-0008 偏差 10）：上游整批回滚，本项目
     部分生效。客户端应当把"部分成功"当作可能结果。
  5. **群目录 `open+langTag` 这一支的翻页语义与上游不同**（ECN-0008 偏差 9）：本项目按
     实际排序键比较，上游这一支自相矛盾。这是一处有意改进，代价是"与上游逐位一致"这条
     口号在这一支上不成立。
  6. **游标不与上游互换**（ECN-0008 偏差 2/3/8）：好友、群组、通知三套游标都是
     base64url(JSON)，精度与字段顺序与上游的 gob 不同。对客户端不透明，但"把上游发的
     游标贴过来"一定解不开，跨实现迁移必须重新拉第一页。
  7. Google 之外的 provider（Apple / Facebook / Steam / GameCenter）仍只有"未配置"守卫。
     这是 v2-social 的显式范围，不是遗漏。
  8. 群组频道准入（`canAccessGroup`）现在读真表，但它排在实时侧的错误路径上：
     非成员看到的是 `Group not found: Invalid channel target`，与"群不存在"不可区分。
     这是上游行为（不泄漏群的存在性），不是缺陷。
  9. E2E 门禁时长继续上升（新增 3 条，全量 174s）。本地 dev 的每请求开销随负载浮动，
     同样全绿的两次运行可能相差数十秒。
